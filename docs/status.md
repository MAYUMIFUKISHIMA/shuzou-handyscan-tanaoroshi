## 再開

1. 最新のmainを取得し、README.md、AGENTS.md、docs/prototype.mdを読む。
2. `python -m inventory.launcher` で起動前バックアップ付きローカル試作を起動する。Python 3.12以上、外部パッケージ不要。
3. fixtures/demo.csvで操作する。data/はローカル専用でGit共有されない。
4. サンプル受領後はdocs/integration-checklist.mdに沿って形式と更新単位を確認する。

## V1の読取経路の訂正

ユーザーの説明はBT-W250が中継機器経由でPCとデータ交換できるという意味だった。PC直結リーダーを使う解釈を訂正する。V1にハンディでの読取・端末内入力保存・中継機器経由の転送を必須として含める。以下のPC入力機能は補助検証用。読取末尾Enter→数量欄、数量Enter→保存/次読取、設定可能なCP932/UTF-8出力を追加。利用者回答で商品コード・商品名・棚卸実数の順、ヘッダーありを確認。正確な列名・文字コード・追加必須項目は未確認。元CSVから候補設定を作成できる。詳細は[v1-pc-pilot.md](v1-pc-pilot.md)。売りex反映・現場スキャナー検証は未実施。

V1は「売りex CSVから対象取り込み → PCで検証 → 中継機器経由でハンディへ対象配布 → 読取・計数 → PCへ回収 → CSV出力 → 売りex反映照合」の全工程を含む。対象CSV取り込みも完了判定から省略しない。
