## 再開

1. 最新のmainを取得し、README.md、AGENTS.md、docs/prototype.mdを読む。
2. `python -m inventory.launcher` で起動前バックアップ付きローカル試作を起動する。Python 3.12以上、外部パッケージ不要。
3. fixtures/demo.csvで操作する。data/はローカル専用でGit共有されない。
4. サンプル受領後はdocs/integration-checklist.mdに沿って形式と更新単位を確認する。
