# 異常系の対応・検証一覧

この一覧は実装したローカル試作の範囲を示す。全ハードウェア・全入力・全障害の網羅保証ではない。

| 対象 | 実装・結果 | 検証 |
| --- | --- | --- |
| CSV型、文字コード、必須列、行、数量、制御文字 | 入力拒否・行別エラー、部分保存なし | 自動テスト |
| 上限超過 | 1MB・5000商品・100列等で拒否 | 商品数の境界とサイズ超過を自動確認 |
| 不正JSON、重複キー、不正型、非有限数値 | 400、サーバー継続 | HTTP自動テスト |
| 同一操作再送、応答消失 | 操作IDと結果をDBに原子的に保存、再実行なし | 再接続・重複・JS通信失敗を自動確認 |
| ブラウザー保存不可 | 送信前に停止 | JSストレージ例外テスト |
| DBロック | 待機上限後に失敗、復旧後に再送 | 実際のSQLite書込ロック |
| DB容量不足 | トランザクション取消 | max_page_countでSQLITE_FULLを再現 |
| DB読み取り専用 | 更新拒否 | SQLite read-only接続 |
| DB破損 | 読み取り拒否、元ファイルを保持 | 不正DBファイル |
| HTTPの保存・読込障害 | 503と復旧案内 | DB/権限エラーの注入 |
| バックアップ失敗・復元 | 既存ファイル保持、整合性検査、新規不完全ファイル除去 | コピー・再読込・権限例外 |
| 未登録バーコード | 保留、照合・理由付き除外、未解決時確定禁止 | 自動テスト |
| 確定後訂正 | 出力前のみ再開、旧確定結果保持 | 自動テスト |
| 出力済み訂正 | 取り込み状況が不明なので拒否 | 自動テスト |
| 同一商品区画の競合・古いrevision | 自動上書きせず拒否 | 自動テスト |

## 制限・現場で残る検証

- JSテストはDOMと通信を模擬したもの。実ブラウザーの視覚・操作、実際のタイムアウト、端末電源断は未検証。
- 容量不足はSQLiteページ上限で再現し、ホストのディスク全体を満杯にする試験はしていない。
- バックアップの別マシン復元、Windowsのファイル権限、長時間の運用は未検証。
- 保存前の未送信入力はブラウザー終了で失われる。送信開始後の未確認操作のみlocalStorageで保持する。ブラウザーの保存領域削除・故障は復旧対象外。
- 開発用の単一PC・単一ブラウザータブを対象とする。認証・権限・公開用サーバーは未実装。
- BT-W250の電源断・転送・保存、売りexのCSV更新単位・部分成功・二重取り込みは実機と仕様待ち。
- 出力後の訂正を自動で進めると外部在庫を二重更新する可能性があるため、売りex側の確認方式が決まるまで禁止する。
