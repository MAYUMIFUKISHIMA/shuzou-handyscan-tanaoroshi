# BT-W250最小アプリの実機試験票

A03を判定するための準備。現在は全項目実機未実施。ホスト模擬試験と混同しない。

前提: 型番/OS/SDKを記録、現場の既存アプリとデータを退避、担当者と検証区画を決定、架空資材だけを使用する。売りex本番へ投入しない。配布方法と復旧手順が決まるまでアプリを削除・上書きしない。

配布する架空品: 000001（箱・基準10）、000002（ラベル・基準20）、000003（緩衝材・基準0）。区画A。メーカー対応を確認したバーコード規格でこれらの文字列を符号化する。ラベル作成時に実際の読取文字列を確認する。

| ID | 手順 | 期待結果・確認資料 |
| --- | --- | --- |
| H01 | 対象一覧を配布し起動 | 正しい棚卸ID・配布版・品番先頭ゼロを保持 |
| H02 | 000001を読取 | 名称・単位を確認できる。終端文字を品番へ混入しない |
| H03 | 実数8を物理キーで入力・保存 | 保存成功後だけ次へ進み、記録IDが付く |
| H04 | 同一区画を7へ訂正 | 合計7、8との履歴を保持。自動加算しない |
| H05 | 数量0と未入力を比較 | 明示ゼロと未棚卸が異なる |
| H06 | 保存直後に正常再起動 | 保存済み記録と未送信状態が残る |
| H07 | 保存中断・電源断を検証用データで試す | 保存成功扱いの記録を失わず、不完全記録を受信しない。再試行可能 |
| H08 | 保存領域不足・保存失敗を再現 | 入力を保持し成功表示しない |
| H09 | 転送前・転送中・PC保存後の応答前に通信中断 | 受領確認前の記録を保持。同じ内容の再送で欠落/二重計上ゼロ |
| H10 | 古い配布版・別棚卸・破損ファイルを送信 | PC側へ一部反映せず拒否 |
| H11 | 同じ商品区画を別端末から送信 | 競合となり自動合算・確定しない |
| H12 | 未登録読取・日本語名称・連続キー操作 | 勝手な商品割当なし。読取/表示/入力の取り違えなし |
| H13 | 端末とPCの全記録を照合 | ID・件数・数量・訂正関係が一致し、全回収後に受領を確認 |
| H14 | アプリ更新と戻し | 保存済み記録を保護し、旧版データの扱いを確認 |

各項目は実施日時、端末/PC/SDK/アプリ版、入力、実結果、証拠保管先、不具合ID、実施者/確認者を追記する。失敗・未実施は未合格。H07/H08の再現方法はメーカーの制約を確認してから選定し、現場データで試さない。
