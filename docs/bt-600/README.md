# BT-600の開発情報

## ユーザーからの確認情報（2026-11-03）

- 出水酒造所有の資産であり、レンタルではない。
- 以前在庫管理に使用、現在は未使用。現場から借用。
- CD等の付属物なし。充電台座とPC転送ケーブルあり。
- 台座にセットしてデータ通信していたとの現場ヒアリング。

## 写真と公式資料で確認した内容（2026-11-03）

- 本体背面の型式はBT-600。台座底面の型式はBT-UC6U。
- 台座にDC INとUSB Type-B端子があり、USB A–Bケーブルが手元にある。PCとの通信成功はまだ未確認。
- 既存の「出水酒造 在庫管理システム」が起動。メニューは原酒在庫・商品在庫・資材在庫。既存データの有無、バックアップ方法、アプリの開発元は未確認。
- [公式BT-600ダウンロードページ](https://www.keyence.co.jp/support/handyterminal/btus/download/bt600/)に、BT-HD10アプリケーション開発マニュアル（C言語）、BT-Navigatorアプリケーション開発マニュアル（BTアプリケーションビルダ）、USBドライバ、データ転送ソフトの掲載を確認。これは掲載説明の確認であり、開発環境導入・ライセンス確保・マニュアル本文の検証は未実施。

次は台座をUSBでPCに接続し、デバイスマネージャーの表示名・COM番号・エラー有無を確認する。過去のPC一覧にあったBT-UC6U（COM3）と同一個体・同一接続とは断定しない。既存の転送ソフトが自動動作する環境では先に設定を確認し、送信・受信・初期化を実行しない。

## 未確認・次の作業

公式のシリーズ開発ガイドでは専用OS系。個体のファームウェア、PCでの認識、既存データの有無を確認する。その後、対応開発ツール/ライセンス/言語/保存方式/転送仕様をメーカー資料本文と照合する。C言語のBT-HD10を調査候補とし、現時点では採用確定としない。

既存アプリの初期化・削除を行わず、保存データの保全方法を確認する。BT-W250のSDKやコードが使える前提にしない。共通棚卸要件と[論理交換契約](../../contracts/README.md)を満たせるか検証する。実機向け実装・ビルド・配布・動作試験はすべて未実施。

[端末ソースの置き場](../../devices/bt-600/README.md)。公式方式が確定したら、このフォルダーにビルド記録・実機試験票を追加する。BT-W250の試験結果をBT-600の成功として引き継がない。
