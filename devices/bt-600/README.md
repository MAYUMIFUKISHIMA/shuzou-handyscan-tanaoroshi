# BT-600用アプリ

端末用ソース・プロジェクト・機種別試験の置き場。現時点では調査段階で、実機用アプリ未実装。

公式ガイド上は専用OS系。BT-W250用のC#プロジェクトやBT-WHD1を流用できるとは扱わない。対応開発ツール、言語、保存/読取/通信APIを確認してから実装する。[機種資料](../../docs/bt-600/README.md)を参照。

共通PC実装は `inventory/`、論理交換仕様は `contracts/`。必要な機種別変換は将来PC側の独立アダプターへ実装する。SDK・ライセンス・現場データはGitへ登録しない。ビルド手順・配布物・試験結果はBT-W250とは別管理する。
